# Pexels and Pixabay media sourcing

Read this reference when selecting stock footage.

- Query both providers when both keys are available. Continue with the available provider if one key is missing, but disclose the missing source.
- Pexels uses `PEXELS_API_KEY`; Pixabay uses `PIXABAY_API_KEY`.
- Search with concrete visual concepts, not an abstract article title. Translate Korean concepts into concise English queries when useful.
- For YouTube, prefer landscape clips at least 1920×1080. Reject portrait-only, tiny, visibly watermarked, static, corrupted, or irrelevant results.
- Download only selected renditions. Preserve provider, creator if supplied, source-page URL, query, and local filename in `SOURCES.md`.
- API availability is discovery, not proof that every use is unrestricted. Check the current provider license and clip-specific restrictions for sensitive, commercial, recognizable-person, trademark, or property uses.
- Do not imply that stock people or locations endorse the video's claims. Avoid misleading documentary juxtaposition.

Map every narration beat to a visual purpose. Mix establishing shots, processes, close-ups, environments, and human context. Reuse a clip only when intentional. Prefer 4–10 second shots and vary pacing with narration.
