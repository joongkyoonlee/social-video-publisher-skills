# 소셜 영상 제작·게시 스킬

Codex에서 쓰레드와 유튜브 영상을 제작·검수하고, 사용자가 요청하면 게시하기 위한 개인 스킬 모음입니다.

| 스킬 | 용도 |
|---|---|
| `threads-video-publisher` | 쓰레드용 영상·설명 제작, Zernio 게시, 게시 상태·설명 재확인 |
| `youtube-video-publisher` | 유튜브 가로 영상 제작, 자막·썸네일·설명·챕터 검수 및 게시 |

## 설치

Codex에 이 저장소의 `skills/threads-video-publisher`와 `skills/youtube-video-publisher`를 개인 스킬 폴더에 설치해 달라고 요청하세요. 직접 설치할 경우 두 폴더를 `~/.codex/skills/`에 복사하면 됩니다. 기존 스킬이 있으면 내용을 비교한 뒤 업데이트하세요.

## 사용 예

- `$threads-video-publisher 이 칼럼으로 3분 세로 영상을 만들고 쓰레드에 게시해줘. 음성은 기존에 등록한 내 ElevenLabs 목소리를 사용해.`
- `$youtube-video-publisher 이 자료로 10분 가로 해설 영상을 만들어 유튜브에 게시해줘.`
- `$threads-video-publisher 이 완성된 영상의 설명을 작성하고 게시 전 검수만 해줘.`

## 필요한 연결과 도구

- 영상 제작: 각 스킬에서 지정하는 제작 환경. 쓰레드 신규 제작은 별도로 설치된 Video Studio를 사용합니다. 이 저장소에 Video Studio 엔진은 포함하지 않았습니다.
- 음성: ElevenLabs와 승인된 사용자 음성 설정.
- 게시: Zernio API 키와 해당 플랫폼의 연결 계정.
- 로컬 검수: Python, FFmpeg/ffprobe. 유튜브의 스톡 검색 도구는 해당 스킬에 적힌 공급자 설정이 필요합니다.

키는 환경변수 또는 사용자가 승인한 환경 파일에 설정합니다. `ZERNIO_API_KEY`, `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` 등이 사용되며 실제 값은 저장소에 포함하지 않습니다.

## 게시 원칙

영상 제작만 요청한 경우에는 게시하지 않습니다. 게시를 요청한 경우 대상 계정과 완성본을 확인하고, 게시 후 실제 상태·링크·등록된 설명을 검증합니다. 쓰레드 게시 보조 도구는 기본적으로 검수만 수행하며 `--execute`를 명시해야 게시합니다. 기존 게시물의 삭제·교체는 별도 요청이 필요합니다.

개인 제작 프로필과 사용자의 초상화 자료가 포함되어 있으므로 이 저장소는 비공개로 관리합니다. 공개 전에는 개인정보·자산 사용 범위와 환경 의존성을 별도로 검토하세요.
